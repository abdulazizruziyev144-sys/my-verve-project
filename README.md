# Verve — Localized Restaurant & WebApp Ecosystem

Verve is a full-stack restaurant ordering ecosystem designed for seamless integration with Telegram WebApps.

## 🚀 Features
- **Frontend Menu (`telegramm.html`)**: Localized web menu ("O‘zbekona ta’m, tez va mazali.") featuring dynamic beverage displays and interactive promotional banners.
- **Backend Bot (`script2.py`)**: Asynchronous Python backend that handles incoming order payloads, manages customer sessions, and synchronizes real-time order history.

## 🛠️ Stack
- **Frontend**: HTML5, CSS3, JavaScript (Telegram WebApp JS SDK)
- **Backend**: Python (`aiogram` / `python-telegram-bot`)
